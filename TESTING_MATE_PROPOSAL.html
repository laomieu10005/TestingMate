Typical Testing Workflow

1. Add Sources
Load C/C++ files, folders, or compile_commands.json with build flags

2. Configure
Select coverage level (C0/C1 or MC/DC), test level (UT/IT/ST), ISO 26262 profile

3. Set Compiler
GCC (default) or custom compiler; include paths and defines merged from build

4. Choose Backend
GoogleTest (default) or CppUTest; auto-generates CMake harness

5. Generate
Preprocess, Clang analyze, generate vectors, create test cases & backend artifacts

6. Execute (Optional)
Run backend and collect coverage (gcov/lcov); Testing Mate parses results

7. Refine (Optional)
Feed backend report to Ollama for LLM enhancement of uncovered paths

8. Review & Sign Off
HTML report, CSV cases, markdown audit checklist for traceability closure
